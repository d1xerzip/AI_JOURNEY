Single Screen View 0.2.1 — публичная бета-версия

Расширение предоставляет веб-страницам искусственную конфигурацию одного
экрана. Дополнительные физические мониторы продолжают работать.

ОБНОВЛЕНИЕ УЖЕ УСТАНОВЛЕННОГО РАСШИРЕНИЯ

1. Распакуй новый ZIP.
2. В старой папке extension замени файлы содержимым новой папки extension.
   Для перезагрузки существующего расширения путь к его папке должен остаться прежним.
3. На странице расширений нажми круглую стрелку «Перезагрузить» у Single Screen View.
4. Проверь, что версия стала 0.2.1.
5. Закрой вкладку проверяемого сайта полностью и открой её заново.

Если проще поставить заново: отключи/удали старую копию и загрузи новую
папку extension через «Загрузить распакованное». Не оставляй одновременно
включёнными две копии. Не удаляй распакованную папку после установки.

ЧТО ИЗМЕНЕНО В 0.2.1

Сохранён нативный объект ориентации экрана и его методы.
Исправлена передача локального искусственного экрана в полноэкранный режим:
браузер выбирает текущий экран, остальные параметры и ограничения остаются
нативными. Это исправляет возможный конфликт запуска сайта, пользователь сообщил, что обновление заработало. Точная причина
предыдущего предупреждения независимо не подтверждена.

В меню расширения есть «Проверить камеру и микрофон» — отдельная локальная
страница с проверками камеры, микрофона и обоих устройств. Проверка запускается
только кнопкой и обычным запросом разрешения браузера. Полученные дорожки сразу
останавливаются; запись и отправка аудио/видео отсутствуют. Результат относится
к странице расширения, а не к разрешениям конкретного сайта. При ошибке отправь
её название и текст из этой страницы.

УСТАНОВКА В CHROME / EDGE НА WINDOWS

1. Полностью распакуй ZIP в постоянную папку на компьютере.
2. Открой chrome://extensions в Chrome или edge://extensions в Edge.
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение» и выбери папку extension,
   в которой лежит manifest.json.
5. Закрепи Single Screen View через меню расширений браузера.
6. Режим включён по умолчанию. Обнови нужную веб-страницу после установки.
7. Значок расширения открывает переключатель режима и кнопку обновления
   текущей вкладки. После любого переключения обнови нужные вкладки.

При включённом режиме изменения применяются ко всем новым и обновлённым
HTTP/HTTPS-страницам этого браузера, включая подходящие вложенные фреймы.
Настройки сохраняются на устройстве. Доступ к HTTP/HTTPS нужен для запуска
прослойки в контексте страниц. Код не делает сетевых запросов и не отправляет
данные на серверы.

ВСТРОЕННЫЙ БРАУЗЕР CODEX

Установка этого расширения во встроенный браузер Codex не подтверждена.
Архив предназначен для обычного Chrome/Edge с возможностью загрузки
распакованных расширений. Это не плагин Codex. Если встроенный браузер
не предоставляет установку расширений, открой нужную ссылку в Chrome/Edge.
В этой сессии расширение не устанавливалось на твой Windows-компьютер.

ЧТО МЕНЯЕТСЯ

- screen.isExtended возвращает false.
- getScreenDetails(), если этот API доступен, возвращает локальный объект
  с одним элементом screens. currentScreen указывает на этот же элемент.
- Размеры, глубина цвета и ориентация фиксируются по текущему экрану
  при загрузке страницы; координаты единственного экрана начинаются с нуля.
- Нативный getScreenDetails не вызывается, реальные события ScreenDetails
  не подключаются к искусственному объекту.
- Доверенные браузерные события change на исходных Screen и ScreenOrientation
  не передаются обработчикам страницы, установленным после прослойки.
- Нативные разрешения браузера, камера, микрофон, getDisplayMedia и диалог
  выбора источника захвата не подменяются. lock/unlock ориентации остаются
  исходными и сохраняют их ограничения и поведение.

ГРАНИЦЫ ПРОТОТИПА

Это не системный драйвер и не гарантия невидимости второго монитора.
Отдельные Windows-приложения и интерфейс браузера для захвата экрана
продолжают видеть физическую конфигурацию. Саму прослойку можно обнаружить.

Расширение не охватывает служебные страницы браузера, другие расширения,
все возможные фреймы и ссылки на API, полученные до включения режима.
Ранее открытые страницы нужно перезагрузить. Отключение регистрации скрипта
не отменяет уже выполненную подмену в старом документе.

Геометрия окна, window.devicePixelRatio, CSS media queries, resize и другие
браузерные механизмы остаются нативными. Они могут позволять косвенные
выводы о конфигурации. Совместимость с неизвестным сайтом на скриншоте
не проверена, и принятие этой конфигурации таким сайтом не гарантируется.

ОТКЛЮЧЕНИЕ И УДАЛЕНИЕ

Открой значок расширения, нажми «Выключить» и обнови нужные страницы.
Для полного удаления открой страницу расширений и нажми «Удалить».
Мониторные настройки Windows расширение не изменяет.
